# Assets

Game assets for tech-lab. 

## Structure

```
Assets/
  items/          ← All item-specific assets. Each item has its own subfolder.
                    See items/README.md for the per-item layout.
  sounds/         ← Sound files (.wav, .mp3) not tied to a specific item
  materials/      ← Shared materials and textures
  maps/           ← Scene / map files
```

Item-specific sounds, materials, or textures should live inside the item's own folder under `items/` rather than here.
